Plugins add modules to the bar; themes change the colours. Everything here
comes from the official repository,
[binarylinuxx/dots-plugins](https://github.com/binarylinuxx/dots-plugins), and
was reviewed before it was merged. The list is read live from it.

<Aside type="tip">
Open one for what it does, its settings and how to install it. To get any of
them today, see [Installing](/plugins/installing/). To add your own, see
[Publishing](/plugins/publishing/).
</Aside>
