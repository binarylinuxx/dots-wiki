## Dashboard

Point at the middle of the top edge and the dashboard comes down out of the
frame; it goes back when the pointer leaves it. `blxshell dashboard` opens it
from a bind.

It has four tabs:

| Tab | Shows |
|---|---|
| Dashboard | weather, this machine and its uptime, a calendar, CPU, memory and disk |
| Performance | CPU and memory over the last minute and a half |
| Media | the active player: cover, progress, controls and synced lyrics when there are any |
| Weather | the forecast |

It opens on the tab you last used, or always on one (**Settings → Panels →
Dashboard**). The weather location comes from your IP address unless you set a
city in **Settings → Bar**.

## Media island

While something plays, a small island under the top edge shows it, and widens
for a few seconds when the track changes. Clicking it keeps it wide. It steps
aside while the dashboard is out. **Settings → Panels → Media island** sets its
size and how long it announces a new track, or turns it off.
