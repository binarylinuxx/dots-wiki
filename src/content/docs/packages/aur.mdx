## Automated Publishing

Use the provided scripts in `arch-deps/`:

```bash
# Interactive mode
./publish-to-aur.sh

# Quick mode (no prompts)
./quick-publish.sh
```

See the [arch-deps folder](https://github.com/binarylinuxx/dots/tree/blxshell-qs-archive/arch-deps) for details.
