Vellum is one C++ program (plus the `blxshell-greeter` login screen) linked
against [vw](https://github.com/binarylinuxx/vw). The metapackages around it pull in the rest of the setup.

## Nix flake

`github:binarylinuxx/dots` provides:

| Output | Contents |
|---|---|
| `packages.<system>.default` | `blxshell` and `blxshell-greeter`, built against vw |
| `packages.<system>.blxshell-custom-fonts` | every font below in one package |
| `packages.<system>.blxshell-font-googlesans` | Google Sans Flex |
| `packages.<system>.blxshell-font-rubik` | Rubik |
| `packages.<system>.blxshell-font-material-symbols` | Material Symbols (Outlined, Rounded, Sharp) |
| `packages.<system>.blxshell-font-readex-pro` | Readex Pro |
| `packages.<system>.blxshell-font-space-grotesk` | Space Grotesk |
| `packages.<system>.blxshell-font-bitcount` | Bitcount pixel fonts |
| `nixosModules.default` | `programs.blxshell.greeter`, the login screen |

```nix
environment.systemPackages = [ inputs.blxshell.packages.${pkgs.system}.default ];
fonts.packages = [ inputs.blxshell.packages.${pkgs.system}.blxshell-custom-fonts ];
```

## Arch (AUR)

| Package | Contents |
|---|---|
| `blxshell-git` | the shell and `blxshell-greeter` |
| `vw-git` | the vw library it is built on |
| `blxshell-fonts` | Google Sans Flex, Bitcount, Rubik, Material Symbols, Readex Pro, Space Grotesk |
| `blxshell-shell` | fish, ghostty, starship, matugen |
| `blxshell-audio` | PipeWire, WirePlumber, pavucontrol, cava |
| `blxshell-hyprland` | Hyprland and its portals |

```bash
yay -S blxshell-git blxshell-shell blxshell-audio
```

## Building from source

- **vw**, with its own dependencies (Vulkan, Wayland, HarfBuzz, FreeType,
  Fontconfig, Cairo, librsvg, libwebp, PipeWire, PAM and others).
  `nix develop` in the repo brings all of it.
- **clang** with C++23, **CMake** 3.25+, **Ninja**, and **glslc** for the shaders

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## At runtime

Every module hides itself when its service is missing, so none of these is
strictly required.

| Used for | Needs |
|---|---|
| Fonts | Google Sans Flex, Rubik, Material Symbols Rounded |
| Volume | PipeWire |
| Media | any MPRIS player |
| Network, Bluetooth, battery | NetworkManager, BlueZ, UPower |
| Wallpaper colours | matugen |
| Screen recorder | gpu-screen-recorder |
| Power menu, keep awake | systemd-logind |
| Workspaces | zwwm or Hyprland |
| Login screen | greetd |

<Aside>
  `blxshell-quickshell-git` and the Quickshell versions of these metapackages are on the
