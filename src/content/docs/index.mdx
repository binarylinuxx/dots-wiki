## What's Included

- **blxshell Vellum** - The shell, in C++ on [vw](https://github.com/binarylinuxx/vw)
- **blxshell-greeter** - A greetd login screen in the lock screen's style
- **zwwm** or **Hyprland** - Wayland compositor
- **Matugen** - Material Design 3 color generation
- **Fish Shell** - Modern, user-friendly shell
- **Starship** - Fast, customizable prompt
- **Ghostty** - GPU-accelerated terminal emulator
